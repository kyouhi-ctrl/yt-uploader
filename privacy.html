隱私權政策 / Privacy Policy

yt-uploader 只由頻道「Will 有數」的擁有者本人使用。工具透過 YouTube Data API 存取的，只有這個頻道自己的影片、字幕、縮圖與播放清單，用途僅限上傳和管理頻道自己的內容。

工具不收集、不儲存、不分享任何其他人的資料；授權憑證只保存在擁有者自己的電腦上，不會傳給任何第三方。

yt-uploader is used only by the owner of the YouTube channel “Will 有數”. Through the YouTube Data API it accesses only that channel’s own videos, captions, thumbnails and playlists, solely to upload and manage the channel’s own content. It does not collect, store or share data about anyone else; the authorization token stays on the owner’s own computer and is never sent to third parties.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
